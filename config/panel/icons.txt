# Card / menu icons available on the panel (Material Design Icons names).
#
# This is the single source of truth. After editing, run:
#     python3 tools/gen_icons.py
# It regenerates config/panel/icon_glyphs.yaml (glyphs compiled into the
# mdi_36 font), the icon list in configurator.js and the preview font
# embedded in configurator.css. Names: https://pictogrammers.com/library/mdi/
#
# Every glyph costs ~0.5 KB of flash. "## Title" lines start a group in the
# web editor's icon picker; other "#" lines are comments.
